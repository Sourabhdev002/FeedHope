# M8 – Daily Check-ins Walkthrough

## Overview
M8 adds interactive daily tracking to the dashboard. Users can now record their progress toward their personalised Health Plan targets (Water, Steps, Sleep, Exercise, and Habits). All progress is persisted to the database and automatically restored on reload.

---

## Architecture

```
src/features/daily-checkin/
  domain/
    # (Schema handles domain validation implicitly for simple metrics)
  application/
    actions.ts           — Server Actions for UPSERTing check-ins and updating metrics
  presentation/
    TrackerGrid.tsx      — Interactive grid for numerical trackers (Water, Steps, Sleep, Exercise)
    HabitTracker.tsx     — Interactive checklist for daily habits
```

### Clean Architecture & Optimistic UI
- **Server Actions**: `updateDailyMetricAction` and `toggleHabitAction` handle atomic database writes. They automatically handle creating the `DailyCheckIn` record for the current day if it doesn't exist yet (Upsert pattern).
- **Client Components**: `TrackerGrid` and `HabitTracker` use React's `useOptimistic` hook. When a user clicks a button, the UI updates *instantly* without waiting for the network roundtrip, providing a snappy, app-like feel.

## Trackers Implemented

1. **Water Tracker** 💧
   - Displays current / target (e.g., `0.5 / 2.8L`)
   - Quick-add buttons for `+250ml` and `+500ml`
2. **Steps Tracker** 👟
   - Displays current / target
   - Quick-add buttons for `+500` and `+1k` steps
3. **Sleep Tracker** 😴
   - Displays logged sleep vs target
   - Plus/minus buttons to adjust in `0.5h` increments
4. **Exercise Tracker** 🏋️
   - Displays logged active minutes vs daily target (weekly/7)
   - Quick-add buttons for `+10m` and `+30m`
5. **Habit Tracker** 🔥
   - Renders the custom checklist generated by the Health Plan Engine
   - Checkboxes instantly toggle completed state and strike through the text

## Database Changes

`DailyCheckIn` model was expanded to store the daily progress:

| Field | Type | Description |
|---|---|---|
| `waterIntakeLitres` | Float | Current water logged today |
| `stepsCount` | Int | Current steps logged today |
| `sleepHours` | Float | Current sleep logged today |
| `exerciseMins` | Int | Current exercise mins logged today |
| `completedHabits` | String | JSON array of habit strings the user checked off today |

## How to Test

1. Ensure you have an active session and have completed onboarding.
2. Go to `http://localhost:3000/dashboard`.
3. Click the **+250ml** or **+500ml** buttons on the Water card. Notice the instant update.
4. Click a few habits in the checklist.
5. **Refresh the page.**
6. The values you entered should remain exactly as you left them, pulled directly from PostgreSQL.
