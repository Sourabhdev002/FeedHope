# FeedHope Beta Test Plan

## 1. Test Objectives
- Validate the core value proposition: Does FeedHope effectively help users track and improve their daily health habits?
- Identify friction points in the onboarding and daily check-in workflows.
- Uncover edge-case bugs and device-specific rendering issues across modern mobile devices.
- Measure baseline engagement metrics (retention, session frequency) to inform post-beta development.

## 2. User Profile
- **Target Size:** 20–30 users.
- **Demographic:** Health-conscious individuals seeking a simplified, all-in-one daily habit tracker.
- **Device Mix:** Mix of iOS (Safari) and Android (Chrome) users.
- **Commitment:** Willing to use the application daily for a minimum of 7 consecutive days.

## 3. Success Criteria
- **Technical:** Zero critical severity bugs (e.g., data loss, inability to log in) reported during the 7-day period.
- **Engagement:** >60% of cohort completes at least 4 daily check-ins in the first 7 days.
- **Satisfaction:** Average exit survey rating of 4/5 or higher on the core tracking experience.

## 4. Bug Reporting Process
- **In-App:** Provide an email link or a simple Typeform embedded/linked in the UI (e.g., "Give Feedback" button in BottomNav).
- **Direct Support:** Users can email support/founder directly.
- **Triage:** Bugs are logged, assigned severity (Low/Medium/High/Critical), and critical bugs are hotfixed within 24 hours.

## 5. Feedback Questions (Mid-Beta Check-in)
1. Was the onboarding process and health plan generation clear?
2. Did you experience any issues logging your daily water, sleep, steps, or exercise?
3. How does FeedHope compare to other health tracking tools you have used?
4. What is the one feature you wish FeedHope had right now?

## 6. Exit Survey (Post 7-Days)
1. How likely are you to recommend FeedHope to a friend? (NPS 1-10)
2. Did FeedHope help you stay more consistent with your health habits this week? (Yes/No/Unsure)
3. Did you encounter any confusing UI or broken elements? Please specify.
4. If you were the CEO, what would you fix or change first?
