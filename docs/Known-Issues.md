# FeedHope Known Issues & Deferred Features

This document tracks items that are acknowledged but not blocking for the private beta release.

## 1. Confirmed Issues
- **Offline Mode:** The application relies heavily on network availability. Optimistic UI updates will fail gracefully and show a toast error if the user loses connection while logging metrics, but there is no persistent offline queue.
- **Form Navigation:** In the onboarding wizard, pressing the physical "Back" button on Android may navigate away from the page rather than going back a step in the wizard.

## 2. Minor UI Polish Items
- **Animations:** Transitions between dashboard tabs (Today vs. Progress) are currently abrupt.
- **Empty States:** The progress dashboard empty state could be more engaging with an illustration rather than an icon.
- **Toast Overlap:** If a user clicks multiple tracker buttons rapidly, the success/error toasts may visually stack and overlap on smaller viewports.

## 3. Future Enhancements
- **Dark Mode:** A comprehensive dark theme toggle to reduce eye strain at night.
- **Push Notifications:** Reminders for daily check-ins instead of relying entirely on user memory.
- **Social Features:** Ability to share weekly progress cards or invite friends for accountability.
- **Integration:** Apple Health and Google Fit syncing for automated step and sleep data retrieval.

## 4. Deferred Features
- **Password Reset:** The "Forgot Password" flow is currently not implemented. For the private beta, users must contact the admin directly for manual password resets or account deletion.
- **Custom Habits:** Users can currently only track pre-defined habits generated by the AI plan. Adding arbitrary user-defined habits is deferred to post-beta.
- **Profile Editing:** Users cannot edit their core health profile (weight, height, goals) after initial onboarding. This will be added in a future profile settings panel.
